Temas de estudio

Aprende paso a paso

Elige un ejercicio de ejemplo para abrir el módulo correspondiente y cargar sus datos.

1. Ecuación lineal

Resolver 2x + 5 = 15.

2. Ecuación con x en ambos lados

Resolver 4x + 8 = 2x + 14.

3. Factorización

Factorizar x² − 5x + 6.

4. Dominio y rango

f(x) = 2x + 3, con dominio real.

5. Composición

f(x) = 2x + 1 y g(x) = x².

6. Límite

Calcular lim x→2 de x² + 2x + 1.

7. Derivada

Derivar f(x) = 2x³ + 4x + 5.

8. Integral

Integrar 3x² + 4x + 6.

9. Máximo o mínimo

f(x) = x² − 4x + 3.

10. Función cúbica del proyecto

f(x) = x³ − 6x² + 9x + 1.
